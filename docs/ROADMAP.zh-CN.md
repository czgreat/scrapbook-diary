# 路线图

**语言：** [English](ROADMAP.md) | 中文

本路线图描述 `scrapbook-diary` 公开仓库的当前状态，并区分已经可用的内容和每个使用者需要在自己环境里补完的内容。

## 已经足够使用

- 图文日记草稿
- 静态部署
- 浏览器本地持久化

## 需要本地补全

- 如需多设备编辑，可补云同步
- 用于备份的导入/导出格式
- 键盘无障碍流程复核

## 建议改进

- 增加本地草稿导入/导出
- 增加浏览器存储迁移测试
- 优化移动端编辑体验
- 增加上传和预览流程的 Playwright 冒烟测试

## 仍值得补充的文档

- 使用非私有演示数据制作截图或短录屏。
- 为常见请求/响应补完整 API 示例页。
- 为持久化数据路径补备份和恢复说明。
- 等公开用户开始部署后，基于真实问题整理排障页。

## 维护说明

- 公开示例保持通用。
- 英文和中文说明保持同步。
- 尽量拆小 issue 和 pull request，方便 AI 辅助贡献者安全接手。
- 发布新版本前重新跑敏感信息扫描。
